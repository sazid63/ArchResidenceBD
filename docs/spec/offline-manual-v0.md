# The offline manual v0 (W5.5): the app's own answers, with no network and no model

**Status:** v0.1.0 — the app can answer a user's question offline, in Bangla or English,
from facts the repo already holds.
**Code:** `core/src/archres_core/manual.py` · `core/src/archres_core/bridge.py`
(`manual.search` ·) · `tools/install/build_manual.py` (the CLI ·) ·
`app/src/screens/HelpScreen.tsx` (the help screen ·) · **Tests:**
`core/tests/test_manual.py` (10) · **Decision record:** ADR-0068 · **Plan:** §10 (the
offline-first law), §5.1 (the app's own guidance)

## What it was

The plan's W5.5 ends with *"the offline manual"*, and the plan's law says the app works with
no internet. So the manual is the one thing the app must be able to answer **with no
network and no model** — and that rules out the obvious implementation: a manual that needs
a model to read it is not offline. Nothing in the repo could answer a user's question about
the app without a model.

## What it is now

- **Derived from the repo's own facts** — the flow book (the questions the app asks and
  why) and the rule packs (the provisions the app applies, with their clauses) — so it is
  generated by a script and never by a model.
- **Every answer is sourced** — the flow question id or the pack's provision and its clause
  — so a user can check it and a support answer can point at it.
- **Every entry is in both languages** — Bangla and English.
- **The search is deterministic** — term overlap, a question's own words counting for more,
  and the order stable, so the same question always gives the same answer.
- **Silence is honest** — a query that matches nothing returns nothing, because a manual
  that invents an answer is worse than one that says "not found".
- **Reachable from the app** — the bridge carries `manual.search` and the app has a **Help**
  screen; in a browser it says plainly that the manual is searched by the core.

## The measured output (2026-10-22)

The manual is built from the flow book and the pack: the flows' goals, the **22** flow
questions, and the pack's **23** provisions — every one of them sourced ✓ ✓.

An English question:

```
  1.50  ask-soil-has-report  [soil-has-report (the flow book)]
        Do you have a soil test report?
        Bearing capacity decides the foundation - without a report we assume the safe area
        default and flag it clearly.
  0.75  ask-foundation-system  [foundation-system (the flow book)]
        Any preference for the foundation type - or should the app decide from the soil?
        The app picks from bearing capacity and load; you can always override later.
```

A Bangla question — the same manual, the other language:

```
  1.50  ask-project-name  [project-name (the flow book)]
        এই প্রকল্পের নাম কী হবে?
        ড্রয়িং, রিপোর্ট আর ইঞ্জিনিয়ার প্যাকে এই নামেই থাকবে।
  0.50  rule-rajuk@2008.1-s54-6-9  [rajuk@2008.1#s54-6-9 §54(6)-(9)]
        নিজস্ব রাস্তা, অ-তালিকাভুক্ত ক্ষেত্র, ফুটপাত সম্পর্কে §54(6)-(9) কী বলে?
        (৬) বেসরকারি আবাসন প্রকল্পের অভ্যন্তরীণ রাস্তা ইমারত নির্মাণ বিধিমালা ২০০৪ অনুসারে...
```

And the refusals: a query that matches nothing returns **nothing** ✓, a stopword-only
query returns **nothing** ✓, and a missing source is an **error** ✓ ✓.

## What is deliberately not here

- **The manual as a PDF** — the app reads it (the screen); a PDF would be a second copy of
  the same facts.
- **Screenshots**.
