- **Package-closure checklist (agreed 2026-10-10, after W1.1's first "done" outran its fixes).**
  A package is not done when the code lands; it is done when **all** of these hold, in order:
  1. the full local gate sweep is green — `pytest`, `tools/ci/py_syntax_check.py`,
     `tools/ci/brand_guard.py`, `generate_spec.py --check`, `generate_interfaces.py --check`,
     and every `--check` freshness CLI relevant to the package;
  2. where models or CAD are touched, a **live probe is recorded in the spec doc** with its
     real output — a stubbed transport is a test, not a verification;
  3. the board and spec numbers are true (or the exact count is removed from prose and left
     to CI output — hand-maintained totals drift);
  4. the package is committed, pushed, and CI is green on the commit;
  5. only then is the box on this board ticked — **last**, never first.
