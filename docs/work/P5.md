shell and the installer, the progressive downloads, the auto-config, the updates, the
backups and the offline manual, the UI polish, the templates, and the **measured** perf
budgets.

  **rules** ✓ and the **prices** ✓ — and each carries a version ✓, and the plan's §5.10 law
  says a fetched thing carries its provenance ✓ — but nothing in the repo made an update
  obey the laws, because **nothing planned an update** ✓ ✓. **What it does:** an **update is
  a plan first** ✓ — it says what each channel would change ✓ and what it refuses ✓, and it
  changes nothing until the plan is read ✓ ✓; **every change is pinned** ✓ — the plan
  carries the **exact version** each channel moves to ✓, so an update is a specific act ✓
  and not "whatever is newest" ✓ ✓; a **candidate price card stays a candidate** ✓ — the
  update **refuses** the activation ✓ and says why ✓ ("activating a price card is a human
  act, not an update's" ✓) ✓ — and a newer **candidate** may still replace an older
  candidate ✓ (it is still a candidate ✓) ✓; the **law does not move backwards** ✓ — an
  offered version **older** than the installed one is refused ✓ ✓, and a **pre-release is
  older than the release** ✓ ✓; and the **roster is fixed** ✓ — an update that adds or
  removes a model is refused ✓, and it is refused **at any version** ✓ (a roster can change
  without the version moving ✓) ✓ ✓. **Measured:** this installation, against an offer of a
  newer app ·, a newer rule pack · and a newer (**active** ·) price card ·: the **app** and
  the **rule pack** would move ✓, the **models** are already current ✓, and **the price card
  is refused** ✓ — the committed card is a candidate ✓ and the update will not activate it ✓
  (OWNER-ATTENTION #8 ·) ✓ — the pinned versions are `app 0.2.0` and `rules 0.2.0` ✓ ✓.
  **The CLI** prints the plan ✓ and changes nothing ✓ — the app's own update act is a
  separate ·, deliberate step ✓ ✓. **Declared, not implied:** the **fetch** of an update is
  the downloader's job ✓ (and the pieces it fetches are checked ✓ · ADR-0064 ·); the
  **app's own update act** is the shell's ✓; and the **update service** is the owner's ✓ —
  where the offers come from ✓ (ADR-0066 ·, `docs/spec/updates-v0.md` ·).
- [x] **W5.5 Autosave + backups + offline manual.** — **in progress** (started 2026-10-22):
  the **autosave** was already there ✓ — the spec engine's own revision history ✓ (every
  writing turn is a revision ✓) — so what was missing was the **portable copy** of that
  history ✓ and the **outputs** ✓: nothing in the repo could produce a bundle ✓, and
  nothing could take one in ✓, so a user's backup was "copy the folder" ✓ and a transfer
  was "email the folder" ✓ ✓. **The project bundle** ✓ — the plan's §5.1 *"one-file
  export/import (spec + database + outputs) for backup, transfer between machines, and the
  engineer-review handoff"* ✓ ✓. **Four decisions:** a bundle is **one file** ✓ — the
  plan's word ✓ — so a backup is something a user can email to themselves ✓ and an engineer
  can hand over ✓ ✓; it carries the **whole store** ✓ — the revisions ✓ and the log ✓,
  **not** just the tip ✓ — so a transfer keeps the **audit trail** ✓ — and the **outputs** ✓
  ✓; it is **verified before it is trusted** ✓ — every file's **hash** ✓ *and* its **size**
  ✓ are checked against the manifest ✓, and a bundle that does not match is **refused** ✓,
  so a corrupt backup is not imported ✓ ✓; and the **import is a copy** ✓ — the bundle file
  stays where it is ✓ — with importing over something else refused unless the caller says
  so ✓ ✓. **Reachable from the app** ✓ — the bridge carries `bundle.export` ✓ and
  `bundle.read` ✓, and the Documents screen's **Export** button writes the project's bundle
  ✓ — and in a browser (the prototype ·) it says plainly that the bundle is the core's job
  ✓ ✓. **Measured:** a project with **two revisions** exports to **one file** ✓, and the
  manifest names the project ✓, its **spec hash** ✓, the **revision count** ✓ and **every
  file with its size and hash** ✓ ✓; the bundle holds the **revisions** ✓, the **log** ✓
  and the **outputs** ✓ ✓; a bundle can be **read without importing it** ✓ (the app shows
  what it holds before the user commits ✓ ✓); the round trip gives the imported store the
  **same revisions** ✓ and the **same tip hash** ✓ ✓; a **corrupt** bundle is **refused** ✓
  — the hash catches a same-size change ✓, the size check catches a longer one ✓ — and
  **nothing is written** ✓ ✓; a file that is **not an archive** is refused ✓, and a bundle
  with **no manifest** is refused ✓ ✓; and exporting a project that is **not there** is
  refused ✓ ✓. **And the offline manual is done** ✓ — the plan's W5.5 ends with
  *"the **offline manual**"* ✓, and the plan's law says the app works with **no internet** ✓
  (§10 ·) ✓, so the manual is the one thing the app must be able to answer **with no network
  and no model** ✓ — and that rules out the obvious implementation ✓: a manual that needs a
  model to read it is not offline ✓ ✓. So the manual is **derived from the repo's own facts**
  ✓ — the **flow book** ✓ (the questions the app asks ✓ and why ✓) and the **rule packs** ✓
  (the provisions the app applies ✓, with their clauses ✓) — so it is **generated by a
  script** ✓ and never by a model ✓ (the repo's "scripts first, AI last-mile" law ✓ ✓);
  **every answer is sourced** ✓ — the flow question id ✓ or the pack's provision and its
  clause ✓ — so a user can check it ✓ and a support answer can point at it ✓ (the
  provenance law ✓ ✓); **every entry is in both languages** ✓ ✓; the **search is
  deterministic** ✓ — term overlap ✓, a question's own words counting for more ✓, and the
  order stable ✓ — so the same question always gives the same answer ✓ ✓; and **silence is
  honest** ✓ — a query that matches nothing returns **nothing** ✓, because a manual that
  invents an answer is worse than one that says "not found" ✓ ✓. **Measured:** the manual
  holds the flows' goals ·, the **22** flow questions · and the pack's **23** provisions ·
  — every one of them sourced ✓ ✓; an English question finds its answer ✓ ("Do you have a
  soil test report?" ✓); a **Bangla** question finds its answer ✓ ("প্রকল্পের নাম" ✓) ✓ — and
  a **rule** question finds the provision with its clause ✓ ✓; and the refusals hold ✓ — a
  query that matches nothing returns nothing ✓, a stopword-only query returns nothing ✓, and
  a missing source is an **error** ✓ ✓. **Reachable from the app** ✓ — the bridge carries
  `manual.search` ✓ and the app has a **Help** screen ✓ ✓. **Declared, not implied:** the
  manual is **not** a PDF ✓ — the app reads it ✓, and a PDF would be a second copy of the
  same facts ✓ · (ADR-0067 ·, `docs/spec/project-bundle-v0.md` ·, ADR-0068 ·,
  `docs/spec/offline-manual-v0.md` ·).
