# Logos

The application icon: a blue building tile with a 3 × 3 grid of light-blue windows, at 256, 128 and 32 px (PNG). Use it for the desktop window, taskbar, installer and app manifest only. Inside screens the sidebar shows the product name in type next to a small indigo tile with a white Lucide building glyph (`primary` fill, `on-primary` glyph, `r-md`). The icon's blue sits close to the indigo accent; don't recolour it.
